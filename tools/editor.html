地图编辑器

城市与地铁 · 开发内部工具 · 地图是主界面，表单在抽屉里

在真实城市底图上直接放置、拖动地标与设施，编辑人口中心、剧情锚点和区域；元数据、配置、任务和经济等设定收进右侧「数据」抽屉。所有改动写回 maps/<id>/source.json，运行时仍读取脚本生成的 data_<id>.js。

也可以把 source.json 拖进窗口
示例地图通过 fetch 读取，需要在仓库根目录启动一个静态服务器（如 python -m http.server 8000），再访问 http://localhost:8000/tools/editor.html；直接双击 tools/editor.html 时请用「打开本地文件」。写回磁盘使用 File System Access API，不支持时会下载 JSON。

地图编辑器

以地图为中心：点选地图上的对象，在右栏改数值；非空间设定在右侧「数据」抽屉。

工作流

打开一张示例地图，或打开 maps/<id>/source.json。地图与 geo_<id>.js 按需载入。
用底部工具放置地标 / 设施 / 职住中心；任务锚点需先在「数据 → 任务」里选中一个任务。
点选对象后拖动改坐标，或在右栏输入精确数值；↑↓←→ 微调选中对象。
在「数据」里改元数据、配置、区域、剧情、经济与用地配方；预检会实时列出结构问题。
保存 source.json，然后在仓库根目录运行 node scripts/map-source.mjs build <id> --in-place。
运行 node scripts/validate-map.mjs --map <id> 做权威校验，必要时调整 mapVersion。

说明

预检只做结构检查（类型、引用、坐标、配置、任务参数）。几何边界、地图指纹、字段级往返一致性仍由 node scripts/validate-map.mjs 与 node scripts/map-source.mjs check 负责。编辑器不参与构建，也不随站点发布。
