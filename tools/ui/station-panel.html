v3 改了什么
  1. 砍掉顶部指标条：四个数已经被下面的半圆环与进出站三块覆盖，重复了。
  2. 运营收支提到第一位、默认展开：这是玩家在经营模式下真正关心的——这个站赚不赚钱、差多少。
  3. 半圆开口朝右、圆弧在左：读数顺序更自然（从左到右），且为右侧留出竖向空间放覆盖人数、三层图例与两个标签。
  4. 净额用 26px 大字＋颜色（正绿负粉），收入/支出两条横条按同一标尺，一眼看出落差。
  5. 收入与支出各自拆成三项，放在净额下面——不用再展开「运营与费用」。
