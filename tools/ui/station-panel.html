v6：按「系统」切成三块
  1. 建设——所有会改变城市的操作（规模、施工方式、配套、上盖、改名、移动），带实时造价。
  2. 经济——只读的钱与地：收支（含 12 月折线）、物业与地价、配套设施与维护费。
  3. 乘客——只读的人与流动：客流（柱状 + 半圆 + 进出换乘）、换乘关系、附近设施。
  4. 宽屏三栏并列（300 + 340 + 340），同一屏看完「能不能建 / 建了赚不赚 / 有多少人用」。
  5. 窄屏三页切换，页签就是三个系统名——玩家不用再猜「我要找的东西在哪个框里」。
