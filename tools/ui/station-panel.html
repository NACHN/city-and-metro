v5 的核心：信息与操作分家
  1. 宽屏：左建设 / 右信息两栏并列，建设面板固定 330px，信息面板 440px。互不干扰，边看数边改。
  2. 窄屏：顶部「信息 / 建设」切页，同一时间只显示一个——原来那种「8 个框 + 修改车站」的长列表彻底消失。
  3. 标题栏只有一个 🔨 图标：宽屏切显示/隐藏，窄屏切到建设页。它是唯一的双向入口。
  4. 「修改车站」从信息面板移除，规模 / 施工方式 / 配套 / 上盖 / 改名 / 移动全部搬进建设面板，并带实时造价合计。
  5. 信息面板因此只剩四块：运营收支、客流、换乘关系、物业与地价、附近设施——全是只读。
