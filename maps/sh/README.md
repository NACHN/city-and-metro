# sh —— 上海大图（v2.7.0 起随包发布）

240×192 格 / 60×48 km / 1990 年 / 约 940 万人的上海，从 Geofabrik 的 `china-latest.osm.pbf` 切出来的一整张图。
与广州大图同一尺度（2880 个小区），开局是浦西一城两市：过江只有两条隧道，浦东还没长起来。

## 范围

```
bbox  31.0000,121.2200,31.4330,121.8507      # 南,西,北,东
proj  121.22,31.433,380.53,443.39            # lon0,lat0,格/经度,格/纬度（250 m 一格）
```

西到虹桥与松江新城东缘，东到浦东国际机场，北到吴淞口与嘉定，南到莘庄与惠南。
覆盖黄浦、静安、徐汇、长宁、普陀、闸北、虹口、杨浦、浦东、宝山、嘉定、闵行、松江与奉贤北部。

## 内容

| 文件 | 说明 |
| --- | --- |
| `source.json` | 地图源码（`scripts/map-source.mjs` 的唯一真源，和其余七张图一致） |
| `../../js/geo_sh.js` | 投影后的地理数据（2.7 MB，由 `gen-geo.mjs` 生成） |
| `../../js/data_sh.js` | 场景数据（片区、地标、人口中心、历史事件与任务） |

## 数据要点

- **32 个片区 + 3 处景区**：按 OSM 的街道/镇边界分组（`streets` 匹配），带开放年份 —— 核心 12 区 1990 年就在；
  浦东：川沙 1990（当时是川沙县城）、张江 1992（高科技园区成立那一年）、金桥 1993、花木与外高桥 1995、
  三林 2003、周康 2005；嘉定/松江/闵行的外围镇街 1993–2010。
  **外围地区 2000**（1990 年这里是近郊农田与小镇，人口门槛 13M 防「提前开放」）。
  界外的惠南、车墩、南桥三个片区已删掉 —— 地图南界在 31.0°N，这些镇根本不在图上。
- **虹桥机场是可建站的地**：`airport.closeYear: 9999` + `buildable: "underground"` + 片区 `open: 1990`，
  用地不开发（292 格 `LU.AIRPORT`），但允许地下设站与地下穿越（10 号线在虹桥 1 号航站楼就是这样）。
  早先写 `open: 2099` 等于永久不开放，`metro.checkSite` 直接拒绝设站。
- **28 个人口中心 / 34 个地标 / 37 处设施**：地标按落成年份出现（东方明珠 1994、金茂 1999、上海中心 2015、
  迪士尼 2016）。火车站与机场写 `pax`（万人次/日，走枢纽通路）；公园、医院、商圈、景点、大学、场馆写
  `w`（占全市该目的吸引的份额）—— 这些设施原先误写成 `pax`，引擎读不到就按 0 算，界面上是「人流 0」，
  v2.8.3 用 `tools/pax-to-w.mjs` 换算成 `w`。
- **道路与桥梁年份**：沪嘉 1988、内环高架 1994、延安高架 1999、外环 2002、中环 2006；
  越江设施从打浦路隧道（1971）、延安东路隧道（1989）到南浦（1991）、杨浦（1993）、卢浦（2003）与一批隧道。
  未列出的道路随所在片区开放。
- **13 条史实事件 + 7 条历史参考任务**：1 / 2 / 3 / 4 号线、8 号线与世博、10 号线与虹桥枢纽、11 号线与嘉定。
- 人口曲线取地图范围口径：1990 年 940 万 → 2020 年 2010 万（不是全市 2490 万，崇明与金山不在这张图里）。
- **长江口与东海来自水利专题面**（`water_extra.wkt`，两条记录：`长江` GB 210101 / HYDC FB010001，
  `东海` GB 250100 海域）：OSM 在长江口只有中心线（`长江南港`、`长江南槽` 两条 `ship=yes` 的水道，
  各 600 m 宽），切出来整个口门是陆地，长兴、横沙也跟宝山连成一片。专题面注进来以后水面从
  79 → 454 km²：长兴、横沙变成两座岛，南港、北港分开，浦东机场以东与南汇东岸有了海，九段沙那块沙洲
  按数据自身的洞留成陆地。
  长江面 81% 在图外（一直给到 120.55°E / 32.0°N），东海面只有 41 km² 落在框内（其余在 121.85°E 以东）。
  注入前按框裁掉 —— 框内断成几块，`gen-geo` 的矩形裁环会把它们沿框边桥接起来，面积多 26%，
  所以裁剪必须自己做，不能留给 `clipRing`。
  **杭州湾（南汇嘴以南）仍在图外**：地图南界 31.0°N、东界 121.85°E，那片海本来就不在图上。

## 已知差异

1. **起步就是堵的**：1990 年只有 3,781 个路网节点、两条越江隧道，市区密度又比广州高，
   实测车均速 14.4 km/h、拥堵 1.94（gz 1990 是 1.04）。这是史实方向，但对玩家偏硬。
2. **地价梯度 1.92×**（gz 3.32×）：与广州大图同一个毛病 —— 面积放大后核心与外围的密度差被摊平，
   TOD 溢价偏小。尚未标定。（长江口成水以后比成水前的 1.69× 略高：水面不再算可建地。）

## 验收

```bash
node scripts/build.mjs                        # 61 文件 / 9 图 / 0 警告
node scripts/map-source.mjs check             # 9/9
node scripts/validate-map.mjs                 # 9/9
node tools/map-check.mjs sh                   # 机场可地下设站、7 个历史任务锚点 0 死局；开局可设站 9,014 格
node scripts/smoke.mjs --maps=sh --months=2   # 三模式 f2649b500c846179 / 3c6c72e6cc64c38a / 5b49abb7e1503845
node tools/region-cells.mjs sh                # 片区 33，空片区 1（滨江森林公园在框外）
node tools/water-cover.mjs sh                 # 水面 1,090 片，水系线落在水面内 8.1%（长江南港/南槽已不再外露）
node tools/month-breakdown.mjs sh --months=2  # 建局 4.3 s，节点 3,584 / 弧 6,694
node tools/preview-map.mjs sh out.ppm         # 底图预览（PPM）
```

## 重新生成

```bash
python tools/osm-cut.py --bbox 31.0000,121.2200,31.4330,121.8507 --out maps/_raw/sh \
  --proj 121.22,31.433,380.53,443.39 \
  --water-extra maps/sh/water_extra.wkt --water-extra-name 长江   # 约 17 min（含裁剪；只重跑收集约 40 s）
node scripts/gen-geo.mjs --from maps/_raw/sh/features.geojson --map sh --w 240 --h 192 \
  --proj 121.22,31.433,380.53,443.39 --out js/geo_sh.js
python tools/_sh-source.py                    # 经纬度表 → maps/sh/source.json
node scripts/map-source.mjs build sh --in-place
node tools/preview-map.mjs sh out.ppm
```

记录名写在它上面一行 `# 名称：X`（`--water-extra-name` 是没有标记时的兜底）。别省：合并后的水面按
「代表点落在哪个具名水面里」取名，不带名字时那片 400 km² 的长江口会被旁边的「川杨河」认领。

`maps/_raw/` 是原始数据与切图产物，已在 `.gitignore` 里，不入库。
