# wlmq —— 乌鲁木齐（v2.8.0 起随包发布）

160×144 格 / 40×36 km / 2000 年 / 约 181 万人的乌鲁木齐，从 Geofabrik 的 `china-latest.osm.pbf` 切出来。
与其他城市最大的不同：**没有江**，城市是一条南北向的带子 —— 东边红山、西边雅玛里克山，
中间是被快速路盖住的乌鲁木齐河故道（河滩走廊）。所有通勤都得挤过这条走廊。

## 范围

```
bbox  43.6767,87.2609,44.0033,87.7791      # 南,西,北,东（比格网各多约 1 km 余量）
proj  87.27,44.003,321.17,443.6            # lon0,lat0,格/经度,格/纬度（250 m 一格）
格网  160 × 144 = 40 × 36 km = 1,440 个小区
```

边界是按"必须框进来"的地点定的：

| 方向 | 地点 | 格坐标 | 说明 |
| --- | --- | --- | --- |
| 西 | 八钢（八一钢铁）、三坪农场、王家沟 | x≈9 / 23 / 27 | 钢铁与农场工业带，2000 年前就存在 |
| 北 | 米泉（现米东城区）、古牧地 | (117, 2) / (126, 18) | 米泉老城贴北界，2007 年设米东区 |
| 东 | 石化基地、卡子湾 | x≈132 / 116 | 以石化为主的工业区 |
| 南 | 仓房沟、三屯碑、乌拉泊 | (95, 112) / (108, 108) | 河滩走廊的南端出口 |

经度方向 321 格/度、纬度 443 格/度 —— 差得大是因为北纬 43.85° 处 1° 经度只有 80 km。

## 数据要点

- **20 个片区 + 3 个景区**：19 个按 OSM 的 level-8 街道边界分组（名字必须一字不差，用 `tools/region-cells.mjs` 验），
  八钢另用一个多边形（OSM 里没有它的街道边界）。**开放年是「这片地方真正开始变成城区」的年份，
  不是它被划成街道的年份** —— 2000 年的乌鲁木齐建成区只有 140 km² 左右：

  | 开放 | 片区 | 依据 |
  | --- | --- | --- |
  | 2000 | 老城三片、西山·雅山、骑马山、六道湾、七道湾·苇湖梁、铁路局、迎宾路·机场外围、卡子湾·石化、古牧地（米泉）、八钢、三坪·王家沟 | 2000 年已经是城区，或本来就是独立城镇（米泉市）/ 大厂（八钢 1951、石化 1970s、卡子湾 1950s） |
  | 2003 | 长春路 | 银川路、杭州路一带的住宅区 |
  | 2006 | 高新区北区（城北） | 二工乡与正扬路一带 2006 年起建工业园；2000 年是农田与村庄 |
  | 2011 | 高铁新区 | 兰新高铁乌鲁木齐站 2011 年开工 |
  | 2012 | 白鸟湖（经开区）、五一新城、外围地区 | 白鸟湖是荒山与戈壁；五一是农场耕地；外围（两河、安宁渠、南山）同理 |
  | 2016 | 河马泉 | 榆树沟、葛家沟一带，图上最晚出现的一片城区 |
  开放年只管「新区」，管不到**街道边界本身有空洞**的地方：OSM 里火车西站的站场与货场、
  石化厂区、米东城区北部都落在 level-8 边界之外，会掉进「外围地区」跟着一起锁到 2012。
  这些地块靠**片区自带多边形**补（`POLY_EXTRA`：火车西站片区补了 x50–66 / y48–58 一块），
  八钢与五一新城则完全是多边形片区。**不要靠把外围放开来解决** —— 一放开，两河、安宁渠、
  五一这些本该锁住的地方就全长回来了（这一版前后反复过两次）。
- **24 个人口中心 / 26 个地标 / 26 处设施**：红山塔（1788）、陕西大寺（1906）、八一钢铁（1951）、
  大巴扎（2003）、会展中心（2013）、乌鲁木齐站（2016）、奥体中心（2019），机场带客流曲线。
  高铁与红光山两处中心在 2000 年只给到村庄量级（8–9 千），后期靠站点可达性自己长起来。
- **13 条史实事件 / 6 条历史参考任务**：事件是真实时间线（2002 启动规划、2007「T 轴」过审、2008 搁置、
  2011 高铁与白鸟湖开工、2012 批复、2014 开工、2018 河马泉、2018/2019 通车）；任务取自当年规划文本，
  按它们**本来该有的年份**考核。

## 机场与新区

**地窝堡机场是可用地**，不是一块永久禁区：`airport` 写 `closeYear: 9999` + `buildable: "underground"`，
片区 `open: 2000`。用地不开发（233 格全是 `LU.AIRPORT`），但**允许地下设站与地下穿越** —— 1 号线就是
这么进机场的。用 `tools/airport-check.mjs wlmq` 可以直接验：

```
机场片区「地窝堡国际机场」开放年 2000 · 跑道格 233 个
设站(underground)：可以
设站(surface)：不行 — 地窝堡国际机场照常运营：范围内只能建地下车站
```

早先这行写的是 `closeYear: 2099` + 片区 `open: 2099`，整片永久不开放：**h1「通到机场」的任务
在数学上就不可能完成**（`metro.checkSite` 直接拒绝设站）。这是这张图 2.8.1 之前最硬的一个 bug。

`tools/airport-check.mjs` 会把「哪一年能在这片设站」整张表打出来，新图加机场时先跑一遍它。

## 这条 IF 线

乌鲁木齐的轨道交通规划比通车早了十六年：

| 时间 | 发生了什么 |
| --- | --- |
| 2002-09 | 市里启动轨道交通线网规划，同年成立轻型轨道筹建小组 |
| 2005-11 | 《乌鲁木齐市城市轨道交通网络规划》获批，成立前期工作小组 |
| 2007-10 | 「三主两辅 T 轴」方案通过专家咨询：5 条线 / 约 166 km / 约 600 亿 |
| **2008** | **本该开工** —— 因未达国家建设标准、未上报国务院，规划终止 |
| 2010-05 | 中央新疆工作座谈会后重启，可研从头做起 |
| 2012-11 | 国务院批准《建设规划（2012—2019）》，线网从「T」改成「X」，先期四条线 76.8 km |
| 2014-03 | 1 号线开工（距搁置六年） |
| 2018-10 / 2019-06 | 1 号线北段 / 全线通车 |

2008 年那版规划的取法是「以外环路为界：环内地下、环外高架」，线网呈 T 字形；
2011 年上报版改成中腰拉长的 X 形。这张图把两个版本都放进了历史任务里。

**地图本身不做任何预置**：一根轨道都没有，玩家自己决定要不要在 2008 年就动工。
历史参考任务（6 条）照着当年的规划文本写：

| 任务 | 走向 | 原定通车 |
| --- | --- | --- |
| h1 1 号线（2008 版） | 三屯碑—解放路—友好路—新医路—北京路—地窝堡机场（26.5 km / 21 站） | 2015 |
| h2 2 号线一期 | 边防局—中环路—人民路—黑龙江路—高铁站—泰山路（18.2 km / 14 站） | 2018 |
| h3 3 号线一期 | 仓房沟—火车南站—扬子江路—友好路—鲤鱼山—长春路（16.9 km / 15 站） | — |
| h4 4 号线一期 | 高铁片区—河南路—铁路局—会展中心—七道湾（15.2 km / 11 站） | 2020 |
| h5 2007 年轻轨 | 火车南站—经济开发区—米东（「沿产业走」的思路） | 2012 |
| h6 2008 版 2 号线北段 | 城北干道—天津路—稻香南路—古牧地（全高架，19 km / 15 站） | 2016 |
- 人口取地图范围口径：2000 年 181 万 → 2020 年 370 万。

## 这张图的特点

| 指标 | 值 | 对照 |
| --- | --- | --- |
| 路网节点 / 有向弧 | 3,298 / 8,078 | gz 1,595 / 4,022；sh 3,781 / 7,132 |
| 建局 / 月步进 | 6.8 s / 2.9–3.2 s | 1,440 个小区 |
| 车均速 / 拥堵 | 29.6 km/h / 1.02 | 181 万人摊在 1,440 km²，起步接近自由流 |
| 地价梯度 | 2.22× | 小图正常范围（gz 3.32×） |
| 外围地区 | 11,693 格（731 km²，51%） | 南北两端的山地与戈壁，图里一半是空的 |

西侧 209–409 是八钢与农场，东侧 291–454 是米东 —— 这就是"带状 + 两个飞地"的形状。

## 重新生成

```bash
python tools/osm-cut.py --bbox 43.6767,87.2609,44.0033,87.7791 --out maps/_raw/wlmq \
  --proj 87.27,44.003,321.17,443.6            # 约 15 min
node scripts/gen-geo.mjs --from maps/_raw/wlmq/features.geojson --map wlmq --w 160 --h 144 \
  --proj 87.27,44.003,321.17,443.6 --out js/geo_wlmq.js
python tools/_wlmq-source.py                  # 经纬度表 → maps/wlmq/source.json
node scripts/map-source.mjs build wlmq --in-place
node tools/region-cells.mjs wlmq
node tools/preview-map.mjs wlmq out.ppm
```

## 已知偏差

- **步行网只有 811 条**（广州是 20,368 条）：乌鲁木齐的 OSM 数据里 footway / path 很少，
  步行接驳的实际连通性比真实差一些，覆盖范围可能偏小。玩家反馈若集中在这点，需要单独补一层人行道。
- **2000 年起步拥堵只有 1.02**，不像"乌鲁木齐很堵"的印象。模型里拥堵由人口密度 × 路网供给算出，
  真实体验里的堵主要来自河滩走廊的单点瓶颈 —— 那要靠玩家把线网与路网堆起来才出现。
- 八钢城区在 OSM 里没有独立的 level-8 街道，它落在 头屯河农场 与外围之间的空档里；
  本图用一个多边形片区「头屯河·八钢」（259 格 / 16 km²，开放年 2000）框住它。
- 「未开放」不等于「没人住」：引擎按人口中心铺 2000 年的人口，不检查片区是否开放，所以外围地区
  在 2000 年仍有约 1,700 格聚落 / 20 万人（城乡结合部的村子）。这些格子在开放前不能建站、不能增长，
  但建筑与人口照常存在 —— 这是全局模型行为，八张图一致，不是这张图的 bug。
