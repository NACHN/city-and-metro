# wlmq —— 乌鲁木齐（v2.8.0 起随包发布）

160×144 格 / 40×36 km / 2000 年 / 约 181 万人的乌鲁木齐，从 Geofabrik 的 `china-latest.osm.pbf` 切出来。
与其他城市最大的不同：**没有江**，城市是一条南北向的带子 —— 东边红山、西边雅玛里克山，
中间是被快速路盖住的乌鲁木齐河故道（河滩走廊）。所有通勤都得挤过这条走廊。

## 范围

```
bbox  43.6767,87.2609,44.0033,87.7791      # 南,西,北,东（比格网各多约 1 km 余量）
proj  87.27,44.003,321.17,443.6            # lon0,lat0,格/经度,格/纬度（250 m 一格）
格网  160 × 144 = 40 × 36 km = 1,440 个小区
```

边界是按"必须框进来"的地点定的：

| 方向 | 地点 | 格坐标 | 说明 |
| --- | --- | --- | --- |
| 西 | 八钢（八一钢铁）、三坪农场、王家沟 | x≈9 / 23 / 27 | 钢铁与农场工业带，2000 年前就存在 |
| 北 | 米泉（现米东城区）、古牧地 | (117, 2) / (126, 18) | 米泉老城贴北界，2007 年设米东区 |
| 东 | 石化基地、卡子湾 | x≈132 / 116 | 以石化为主的工业区 |
| 南 | 仓房沟、三屯碑、乌拉泊 | (95, 112) / (108, 108) | 河滩走廊的南端出口 |

经度方向 321 格/度、纬度 443 格/度 —— 差得大是因为北纬 43.85° 处 1° 经度只有 80 km。

## 内容

| 文件 | 说明 |
| --- | --- |
| `source.json` | 地图源码（`scripts/map-source.mjs` 的唯一真源） |
| `../../js/geo_wlmq.js` | 投影后的地理数据（约 360 KB，由 `gen-geo.mjs` 生成） |

## 数据要点

- **18 个片区 + 3 个景区**：按 OSM 的 level-8 街道边界分组（名字必须一字不差，用 `tools/region-cells.mjs` 验）。
  老城三片（大小十字、二道桥/南郊、友好路）2000 年就在；米东 2007（工业带与古牧地城区两片）、
  高铁新区 2011、长春路 2005；西侧八钢/三坪/王家沟是 2000 年就有的工业带。
- **23 个人口中心 / 26 个地标 / 26 处设施**：红山塔（1788）、陕西大寺（1906）、八一钢铁（1951）、
  大巴扎（2003）、会展中心（2013）、乌鲁木齐站（2016）、奥体中心（2019），机场带客流曲线。
- **11 条史实事件 / 6 条历史参考任务**：外环路 2004、米东设区 2007、高铁站 2016、
  地铁 1 号线 2018 北段 / 2019 全线。
- 人口取地图范围口径：2000 年 181 万 → 2020 年 370 万。

## 这张图的特点

| 指标 | 值 | 对照 |
| --- | --- | --- |
| 路网节点 / 有向弧 | 3,298 / 8,078 | gz 1,595 / 4,022；sh 3,781 / 7,132 |
| 建局 / 月步进 | 6.8 s / 2.9–3.2 s | 1,440 个小区 |
| 车均速 / 拥堵 | 29.6 km/h / 1.02 | 181 万人摊在 1,440 km²，起步接近自由流 |
| 地价梯度 | 2.22× | 小图正常范围（gz 3.32×） |
| 外围地区 | 11,822 格（739 km²，51%） | 南北两端的山地与戈壁，图里一半是空的 |

路网在 4×4 分块上的分布（km）：中间两列 477 / 803 / 882 / 348 远高于两侧，
西侧 209–409 是八钢与农场，东侧 291–454 是米东 —— 这就是"带状 + 两个飞地"的形状。

## 验收

```bash
node scripts/build.mjs                        # 61 文件 / 9 图 / 0 警告
node scripts/map-source.mjs check             # 9/9
node scripts/validate-map.mjs                 # 9/9
node scripts/ground-check.mjs                 # 九图底图可绘制
node scripts/smoke.mjs --maps=wlmq --months=2 # 三模式，指纹 7f25525fb2555696
node tools/month-breakdown.mjs wlmq --months=3
node tools/region-cells.mjs wlmq              # 18 个片区都有格子，0 个空片区
node tools/preview-map.mjs wlmq out.ppm
```

## 重新生成

```bash
python tools/osm-cut.py --bbox 43.6767,87.2609,44.0033,87.7791 --out maps/_raw/wlmq \
  --proj 87.27,44.003,321.17,443.6            # 约 15 min
node scripts/gen-geo.mjs --from maps/_raw/wlmq/features.geojson --map wlmq --w 160 --h 144 \
  --proj 87.27,44.003,321.17,443.6 --out js/geo_wlmq.js
python tools/_wlmq-source.py                  # 经纬度表 → maps/wlmq/source.json
node scripts/map-source.mjs build wlmq --in-place
node tools/region-cells.mjs wlmq
node tools/preview-map.mjs wlmq out.ppm
```

## 已知偏差

- **步行网只有 811 条**（广州是 20,368 条）：乌鲁木齐的 OSM 数据里 footway / path 很少，
  步行接驳的实际连通性比真实差一些，覆盖范围可能偏小。玩家反馈若集中在这点，需要单独补一层人行道。
- **2000 年起步拥堵只有 1.02**，不像"乌鲁木齐很堵"的印象。模型里拥堵由人口密度 × 路网供给算出，
  真实体验里的堵主要来自河滩走廊的单点瓶颈 —— 那要靠玩家把线网与路网堆起来才出现。
- 八钢城区在 OSM 里没有独立的 level-8 街道，它落在 头屯河农场 / 三坪农场 之间；
  本图把它归进"头屯河·八钢·三坪"工业片（2,355 格 / 147 km²），没有单独建片区。
